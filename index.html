Speech

  • Double-click a verse to start speech for that language column.
  • Play/Pause button toggles speech. Space bar also toggles play/pause.
  • Stop button or Esc stops speech, clears highlight, and hides speech controls.
  • Speed button (for example 1.0x) opens speed selection.
  • Voice button opens voice selection for the current language.
  • From Speed or Voice selection, returning to play restarts the current verse.
  • When speech reaches the end of a verse, it continues to the next verse automatically.
  • If the language has no available speech voice, an alert is shown and speech stays idle.
  • The available voices depend on the browser and operating system. So, try another browser or OS if needed to get a voice you want.
