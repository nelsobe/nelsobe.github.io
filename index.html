1.0 The Navigation Bar

The icons across the top of the screen provide quick access to common functions such as book/chapter navigation, languages selection, text size adjustment, and speech controls. Experiment with them to find the best way to use them for your needs.

2.0 Using the Text-to-Speech Reader

Double click any verse to start speech playback in that language.

The speech controls are located at the top of the screen once speech playback is initiated. You can use them to control the playback of the text-to-speech reader.

The following are the available speech controls:

  • Press the play button to start or pause narration. Long-press the play button to adjust the speech speed.
  • Press the stop button to cancel playback immediately.
  • Choose a voice with the microphone icon. For some languages, no voices may be available.
  • Hitting the ESC key on a keyboard will stop the current playback.

2.2 Voice selection

The speech voice list is filtered by language. If no voice is available, the microphone icon will do nothing and playback cannot start for that language.

The voices supported are those available in the browser's speech synthesis API. Thus each browser (Chrome, Firefox, Safari, etc.) exposes a different set of voices, and availability may also vary across operating systems.

Some languages may have multiple voices available while others may have none. If a voice you expect is missing, it is likely due to browser or OS limitations for that language.

3.0 Scripture Availability

Not all volumes are available in all languages. For example, the Old Testament may not be available in certain languages, and the New Testament is also missing for some languages.

4.0 Language Availability

The languages provided reflect community interest. Additional languages can be added if there is demand — let me know which language you would like included.
